PYCALPHAD CPU EQUILIBRIUM ALGORITHM SEGMENTS
============================================

This document divides the equilibrium calculation algorithm into 40 logical segments for detailed comparison with GPU implementation.

SEGMENT 1: ENTRY POINT AND PARAMETER VALIDATION
File: pycalphad/core/equilibrium.py:68-82

==================================
LOOP TRACING FOR FIRST 3 ITERATIONS
==================================

For the main equilibrium solver loop (Segments 17-23):

ITERATION 1:
- Initial phases from starting point (usually 1-2 phases)
- Solve for equilibrium with initial phases
- Check for new stable phases in grid
- Often adds 1-2 metastable phases

ITERATION 2:
- Solve with expanded phase set
- Some metastable phases may drop out (NP -> 0)
- Check again for new phases
- Usually fewer additions than iteration 1

ITERATION 3:
- Solve with refined phase set
- System approaching equilibrium
- Rarely adds new phases
- Often reaches convergence

For multiple condition sets, the first three typically show:
- Condition 1: Single phase region or simple two-phase
- Condition 2: May be similar or show phase transition
- Condition 3: Continues pattern or shows new behavior

The exact behavior depends on the phase diagram region being calculated.
