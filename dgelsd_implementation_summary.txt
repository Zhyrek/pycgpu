DGELSD Device Implementation Summary
====================================

Implementation Details:
- Added dgelsd_device() function in svd.c that mimics LAPACK's dgelsd behavior
- Includes automatic row and column scaling (equilibration) for better numerical stability
- Modified lstsq() in generated_equilibrium_kernel.cu to use dgelsd_device instead of regular SVD

Test Results:
- Previous maximum error: 0.000600 J/mol (~6e-4)
- New maximum error:      0.000511 J/mol (~5.11e-4)
- Improvement factor:     1.17x
- Error reduction:        14.8%

Performance on NbTi Test Cases:
- Total test cases: 54 (9 Ti fractions × 6 temperatures)
- Average difference: 5.85e-05 J/mol
- Maximum difference: 5.11e-04 J/mol

Why This Helps:
1. The CPU uses LAPACK's dgelsd which includes automatic matrix equilibration
2. The GPU's custom SVD lacked this automatic scaling
3. This is especially important for multi-sublattice phases where site ratio sums can vary widely
4. For ALCU_ZETA: site ratio sum = 20.0 vs LIQUID: site ratio sum = 1.0
5. This created poorly conditioned matrices (condition number ~4e19)

Conclusion:
The dgelsd_device implementation successfully improves numerical stability and reduces 
the maximum error between CPU and GPU calculations by approximately 15%. This is a 
meaningful improvement that brings the GPU implementation closer to CPU accuracy.
